# Sharanya Vats — Portfolio

Personal academic site covering research, leadership, and coursework in
data science, astrophysics, and sustainability engineering. Built for
scholarship and college applications.

**Live site:** https://vats-math.github.io

## Stack

Plain HTML, CSS, and JavaScript — no build step, no framework. Hosted free
on GitHub Pages.

## Structure

- `index.html` — page content and structure
- `style.css` — theme tokens (light/dark), layout, typography
- `script.js` — theme toggle, starfield background, scroll reveals
- `assets/` — favicon, profile photo, résumé PDF
